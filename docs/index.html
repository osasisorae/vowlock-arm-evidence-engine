The experiment

One changed variable.

  1. Freeze the comparison.
    Same Qwen2.5 1.5B Q4_0 file and hash, pinned llama.cpp, four threads, prompt/generation sizes and Arm64 runner class.
  2. Change KleidiAI only.
    Build once with GGML_CPU_KLEIDIAI=OFF and once with it enabled.
  3. Prove the backend.
    The optimized log must select the CPU_KLEIDIAI buffer and I8MM kernels; the baseline must not.
  4. Measure and replicate.
    Runs 4–6 executed the identical commit. Every run produced the same direction: a small prompt gain and a generation regression.
  5. Verify output separately.
    Run 7 requires both runtimes to produce exactly READY and rejects equal-but-wrong outputs.
Why it matters

Optimization needs an evidence trail.

Small local models can make private Setup Companion guidance possible where connectivity, specialist support and compute are limited. But enabling an accelerated backend is not evidence that the user experience improved. This repository is a reusable pattern for Arm developers: verify selection, compare fact-equivalent conditions, preserve raw evidence, replicate, and keep regressions visible.

Version 1 claim boundary: the one-token contract is an equivalence canary. It does not establish that free-form device guidance is factual, safe or useful. Version 1 did not independently measure peak process memory; Version 2 below does.

Authority allocation · Version 4

COMPLETE · NATIVE ARM

The best model was no model.

Version 3 showed that runtime tuning could not repair a model that failed the product contract. Version 4 moved every decision, evidence identifier and next action into deterministic code. The model could only explain that immutable envelope; rejected prose fell back once to a deterministic template.

DETERMINISTIC TEMPLATE12/120.0816 ms median · no model artifact
CONSTRAINED MODEL6/123.0608 s median · 1.066 GB artifact

The hybrid passed 12/12 registered automatic checks only because six cases fell back. Its model server reached about 2.05 million KiB peak RSS. A disclosed qualitative audit also found that the surface verifier accepted misleading prose, so automatic acceptance is not presented as factual safety.

Decision: retain the deterministic template. Removing the model eliminates seconds of latency, roughly two gigabytes of resident model-server memory and an unverified natural-language failure surface. No human-comprehension advantage has been demonstrated.
